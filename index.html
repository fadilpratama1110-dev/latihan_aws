LKPD Praktik VPS AWS

Fase 1: Pengenalan VPS & Cloud

Memahami layanan hosting dan server cloud

1. Pengertian Server dan Cloud

Server adalah komputer yang menyediakan layanan atau data untuk komputer lain.

Cloud Computing adalah penggunaan sumber daya komputasi melalui internet, misalnya untuk menjalankan server dan menyimpan data.

Dalam materi ini, kita akan mempelajari empat layanan, yaitu Shared Hosting, Dedicated Server, Amazon Lightsail, dan Amazon EC2.

2. Jenis-Jenis Layanan

Hosting Bersama

Shared Hosting

Layanan hosting yang memungkinkan beberapa pengguna berbagi sumber daya dalam satu server.

Contoh sederhana: seperti tinggal di rumah bersama dan menggunakan fasilitas yang sama.

Server Khusus

Dedicated Server

Server fisik yang digunakan khusus oleh satu pengguna atau organisasi.

Contoh sederhana: seperti memiliki rumah sendiri sehingga kendali lebih besar.

Cloud Sederhana

Amazon Lightsail

Layanan cloud AWS yang memudahkan pengguna membuat dan mengelola server virtual.

Keunggulan: pengaturan lebih sederhana untuk memulai menggunakan cloud.

Cloud Fleksibel

Amazon EC2

Layanan AWS untuk membuat dan menjalankan server virtual yang disebut instance.

Keunggulan: konfigurasi server dapat disesuaikan dengan kebutuhan.

3. Tabel Perbandingan

Layanan Pengertian Ciri Utama
Shared Hosting Banyak pengguna berbagi satu server. Sumber daya digunakan bersama.
Dedicated Server Satu server fisik untuk satu pengguna. Kendali lebih besar.
Amazon Lightsail Layanan server cloud yang sederhana. Mudah untuk pemula.
Amazon EC2 Layanan server virtual AWS. Fleksibel dan dapat dikonfigurasi.

4. Kesimpulan

  • Shared Hosting: server digunakan bersama oleh banyak pengguna.
  • Dedicated Server: server fisik digunakan khusus oleh satu pengguna.
  • Amazon Lightsail: layanan cloud AWS dengan pengaturan sederhana.
  • Amazon EC2: layanan server virtual AWS yang fleksibel.
